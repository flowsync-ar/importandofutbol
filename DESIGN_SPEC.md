# Importando Fútbol LP — Dirección visual

## Concepto
Una tienda deportiva con estética premium, oscura y urbana, usando el negro/blanco del logo y el dorado como acento. La web debe sentirse futbolera sin parecer una web genérica de deportes.

## Paleta
- Fondo principal oscuro: `#050505`
- Negro elevado: `#111111`
- Blanco: `#FFFFFF`
- Fondo claro: `#F7F7F4`
- Dorado principal: `#D69A1B`
- Dorado brillante / CTA: `#F2B72A`
- Gris texto: `#6B7280`
- Bordes: `#E6E6E1`

## Tipografía
- Recomendación: **Inter** para UI y cuerpo.
- Para titulares con más carácter: **Oswald**, **Barlow Condensed** o **Anton**.
- Hero grande, comprimido y con alto contraste.

## Layout
- Desktop max-width: 1240px.
- Mobile-first.
- Header sticky.
- Hero oscuro con CTA dorado.
- Cards de producto limpias, foto grande, poco ruido visual.
- Navegación: Inicio / Camisetas / Selecciones / Clubes / Retro / Contacto.

## Home
1. Topbar corta con ubicación/canal de contacto.
2. Header + buscador + favoritos + carrito.
3. Hero con claim “Fútbol que se viste.”
4. Categorías.
5. Productos destacados.
6. Banner de consulta por camiseta específica.
7. Beneficios.
8. Footer.

## Página de listado
- Breadcrumb.
- Título + contador.
- Filtros: equipo, selección/club, talle, temporada, tipo (player/fan), retro, precio.
- Orden: relevancia, más nuevos, precio asc/desc.
- Desktop: sidebar filtros + 3/4 columnas.
- Mobile: botón “Filtrar” con drawer.

## Producto
- Galería 2 columnas desktop / carousel mobile.
- Nombre, categoría, precio, selector de talle.
- CTA principal dorado “Consultar / Comprar”.
- CTA secundaria WhatsApp.
- Guía de talles en modal.
- Bloque de detalles, versión y personalización si aplica.
- Recomendados.

## UX de conversión
- WhatsApp flotante discreto.
- El botón principal debe incluir el nombre del producto en el mensaje.
- Mostrar siempre guía de talles cerca del selector.
- En mobile CTA sticky al pie en ficha de producto.
- Evitar popups agresivos.

## Imágenes
- Fondo neutro gris claro o negro.
- Misma relación 4:5 en catálogo.
- Mantener la camiseta grande y centrada.
- No mezclar estilos de foto dentro de una misma grilla.
